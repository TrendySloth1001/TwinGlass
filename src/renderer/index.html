Mob Mirror

    Add a wireless device

    1. Connect the phone to the same Wi-Fi as this Mac.
    2. On the phone: Settings → Developer options → Wireless debugging (turn it on).
    3. Tap Pair device with QR code and scan:

    1. On the phone: Wireless debugging → Pair device with pairing code.
    2. Enter the IP address & port and the 6-digit code it shows.

    For an already-paired phone: use the IP address & port on its Wireless debugging screen (it differs from the pairing port). For a phone set up with adb tcpip, use port 5555.

    Android 10 or older? Plug the phone in by USB and press Wi-Fi next to it in the device list. That uses the older, unencrypted adb tcpip mode.

    Choose a device to start mirroring.
